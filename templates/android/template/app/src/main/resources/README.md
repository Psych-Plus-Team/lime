This folder contains Java-style resources copied into every generated Android app project.

Files placed here are intended for Android/Google verification flows that should not live in the game repository.

Current file:
- adi-registration.properties: package ownership verification token for com.leninasto.plusengine.

Keep sensitive values here in the Lime template if you do not want them tracked in the game repo.
If Lime is updated or the template is replaced, restore this folder before building Android again.
